# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| 0.1.x | No. It allows remote file writes anywhere on the server and remote crashes. Upgrade. |

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/Jamalianpour/EasyFileTransfer/security/advisories/new)
with steps to reproduce. You should get a response within a week.
